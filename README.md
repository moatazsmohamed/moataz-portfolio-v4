# معتز محمد — بورتفوليو فل ستاك

موقع بورتفوليو احترافي (عربي/إنجليزي) مع لوحة تحكم كاملة، مبني بـ **Next.js 15 + Prisma + PostgreSQL**.

## المميزات

- 🎨 واجهة داكنة احترافية بحركات وانتقالات ناعمة (مستوحاة من أفضل ما في بورتفوليوهات Full-Stack).
- 🌐 دعم كامل للعربية (RTL) والإنجليزية (LTR) بتبديل فوري.
- 🗂️ أقسام: الهيرو، من أنا، المشاريع، المهارات، الخبرات، الشهادات، التواصل.
- 🔐 لوحة تحكم `/admin` بتسجيل دخول آمن (JWT في httpOnly cookie + bcrypt).
- ✏️ تحكم كامل: المعلومات الشخصية، المشاريع (إضافة/تعديل/حذف)، المهارات، الخبرات، الشهادات، ورسائل التواصل.
- 🖼️ رفع صور من لوحة التحكم (تُخزَّن في قاعدة البيانات وتُقدَّم عبر `/api/media/[id]`).
- 📬 نموذج تواصل حقيقي يحفظ الرسائل في قاعدة البيانات وتظهر في اللوحة.
- 📊 عدّاد زيارات.

## التشغيل محليًا

```bash
npm install
cp .env.example .env      # ثم عدّل القيم
npx prisma db push
npx tsx prisma/seed.ts    # ينشئ الأدمن + البيانات الأولية
npm run dev
```

الموقع: http://localhost:3000 — لوحة التحكم: http://localhost:3000/admin

## متغيرات البيئة

| المتغير | الوصف |
|---|---|
| `DATABASE_URL` | رابط PostgreSQL (Neon / Supabase / أي Postgres) |
| `AUTH_SECRET` | سر توقيع جلسة الأدمن — 32 حرف عشوائي على الأقل |
| `ADMIN_EMAIL` | إيميل الأدمن الأول (يُنشأ تلقائيًا) |
| `ADMIN_PASSWORD` | كلمة مرور الأدمن الأول |

> ⚠️ لا تضع أي توكنات (GitHub/Vercel) داخل الكود — تُضاف فقط كمتغيرات بيئة على المنصة.

## النشر على Vercel

1. اربط الريبو بمشروع Vercel.
2. أضف متغيرات البيئة الأربعة أعلاه (Production + Preview).
3. أمر البناء يعمل تلقائيًا: `prisma generate && prisma db push && tsx prisma/seed.ts && next build`.
